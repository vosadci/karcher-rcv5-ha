# Instructions for AI agents

If you are an AI agent preparing an issue or pull request for this repository,
follow `CONTRIBUTING.md`'s "AI-assisted contributions" section before
submitting anything:

- Disclose that AI assistance was used, and which parts.
- Verify every claim, log, and capture against something actually run or
  read. Never fabricate one.
- Do not submit an issue or PR a human hasn't reviewed and understood.
- Do not fill a required field with content that isn't a real answer.
